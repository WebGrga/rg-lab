Momentum Lab

Momentum Lab treats self-improvement like a lab: a hypothesis, metrics, a deadline and a verdict for every experiment.

Routines, notes, ideas and a weekly review live beside it, and all of it stays on your device.

Open the app →Code on GitHub ↗

What it shows

  • A real working app. Log a value, tick a routine, close an experiment with a verdict: it all saves.
  • Metrics that know direction. Each metric knows whether up or down is better and compares against its baseline.
  • The Base. Seven foundations (body, mind, habits and more) roll up into one radar of where you stand.
  • Local-first. No account and no server: data stays in your browser, with JSON export and import. The desktop build writes a real file via Electron.

About this demo

The app opens with sample experiments, routines and notes so there is something to click. Changes save only in your own browser; Data → Reset brings the sample back.

This is the same code as the desktop app, built for the browser.
